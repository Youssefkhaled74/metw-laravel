PART TEN: SHIPPING COST CALCULATION SYSTEM
Overview
System automatically calculates shipping cost

System automatically distributes shipping cost to all parties in the shipping/delivery route (each warehouse and representative's share + company share)

Admin Configuration Options
For EACH party in the shipping/delivery route (warehouse or representative):

Option	Description
Option 1	System automatically sends calculated fee to representative/warehouse with the assigned request
Option 2	Representative/warehouse enters their own fee value when accepting the assigned request
Note: The selected option remains active and saved until admin activates and saves the other option.

Shipping Route Calculation (With Warehouses)
If each delivery representative and each warehouse enters their own fee value when accepting the request:

Formula for Shipping Representative Fee:

text
Shipping Representative Fee = (Delivery Representative Fee × 1) + (Sender Warehouse Fee × 1) + (Receiving Delivery Representative Fee × 1) + (Sender Delivery Representative Fee × 1) + 8
Note:

The numbers (1 and 8) in the formula can be modified and saved by admin at any time

All parties in the equation have the same coefficients

Shipping Representative Workflow
Shipping representative selects multiple sub-shipments from a consolidated order that includes multiple sub-shipments

Each sub-shipment has its own shipping representative fee value

Excel Files Provided
#	File Name
1	Shipment Classification File (ملف تصنيف الشحنات)
2	Representative Categories File (ملف فئات المناديب)
3	Governorate Distance Matrix File (ملف مصفوفة كودات بعد المحافظات)
4	Shipping Cost & Representative/Warehouse Fee Calculation File (ملف حساب تكلفة الشحن وأجرة المناديب والمستودعات)
PART ELEVEN: SELLER BRANCHES (WAREHOUSES) & STORE WAREHOUSES
Seller Branch Addresses
When entering store data, the seller enters and saves their branch (warehouse) addresses:

Each branch number has an associated branch name and address data

Branch numbering: Branch 1, Branch 2, Branch 3, Branch 4, Branch 5, Branch 6, Branch 7, ...

Store Warehouse Usage Process
Seller uses warehouses that have accounts in the system (Warehouse Account from Part Nine)

Seller selects warehouse account number from registered warehouses list

Seller adds product code + product quantity

Seller sends the request

Seller waits for warehouse account owner to approve shipping the product to the warehouse

After warehouse approval, seller creates a shipping request from one of their branch addresses to the warehouse address
